# Open questions and publication gates

1. **Source feature timing:** Approval-time versions of initial rate, amount, guarantee, processing method, revolving status and collateral have not been independently checked against contemporaneous records. Use retrospective wording.
2. **Strict-cohort selection:** Eligibility depends on later status and term validity. Results do not generalize automatically to all originations; a clean approval-time cohort would require redesign and additional data.
3. **Confirmatory evaluation:** FY2013/FY2014 are development years; FY2015/FY2016 results were inspected earlier. Do not claim an untouched final test. If prospective performance is a goal, obtain later independent data with consistent outcome maturity.
4. **Calibration:** Mean prediction and top-risk decile underestimate FY2014 observed risk; subgroup differences need disclosure. No decision threshold or live-use recommendation is established.
5. **External benchmark:** Do not advertise a direct reproduction of a published reference benchmark without matching its data, target, split and evaluation design.
6. **Repository disclosure:** Check data-source usage terms; decide on the code license; scan public commits for raw data; retain exact manifests/checksums.
7. **Human review:** Manually check the model card, target definition, assumptions, source citations, financial interpretation and any CV/SOP claims before publishing.
